# SahiBhav audit fixes — 30 October 2026

## What this release changes

- Market comparison quotes retain commodity, market, variety, grade, unit and actual observation date. Basava Kalayana wheat no longer combines Mexican and Mill Quality into a fictional Mexican quote. Automatic calculator pairs require matching known identity and date and recent observations.
- Seven-day windows contain seven inclusive calendar dates. Collection gaps are described as missing from our archive, without asserting that the upstream source failed.
- The advice hub discovers published Hindi CMS articles and searches their bodies. Processed rice, poha and atta do not inherit cultivation guides for paddy or wheat.
- Blog pagination has distinct prerendered clean routes and self-canonicals. Legacy pagination redirects retain filters. Filtered collections remain noindex.
- Routing middleware evaluates price-page expiry at request time and removes expired URLs from the sitemap, independently of the next ingestion/rebuild. Price history remains accessible to people. Crop policy is 90 days; mandi policy requires three distinct commodities within 30 days. These are product thresholds, not Google requirements.
- Delivery example supplies a fictional 80 km distance and produces a complete result. Vehicle/capacity inputs appear before the optional gallery and long reference material.
- Seven new catalog identities receive explicit neutral fallback artwork pending source/form verification. Fine/superfine/grade-A rice and paddy have distinct display labels.
- Ingestion no longer treats a matching first page or unchanged count as proof that every record is stored. Probe failures cannot be reported as successful refreshes; retries and pagination are bounded.

## Deployment and data operations

The existing founder Mac ingestion schedule is documented in PILOT-PLAN-2026-10-16.md (08:30 and 20:30 IST). GitHub ingestion is deliberately disabled because the upstream service refuses that network path. This release does not enable it, revive old laptop tasks, modify keys or verify the Mac scheduler.

The source build regenerates derived data before Vite/prerender, so comparison semantics are deployed with their matching data. Raw daily snapshots are available to the build but remain excluded from deployed API function bundles. Generated data and SEO manifests are build artifacts; the source release does not replace the stored raw observations.

The fetcher now requires `DATA_GOV_API_KEY` in that existing environment; the inline fallback was removed before publication. A missing or blank variable fails before a network request.

Operator diagnostic: `node scripts/fetch-daily.cjs --probe` performs one bounded request and does not modify stored data. Run it only in the existing authorized operator environment with its configured credential. Never paste credentials or full authenticated URLs into logs/issues.

## Search Console follow-up

User supplied aggregate exclusion counts: 28 noindex, 19 404, 5 proper canonical alternatives, 1 redirect, 533 crawled/currently not indexed, 4 Google-selected canonical conflicts. Validation is Started. No affected-URL export or Search Console account access was supplied.

Do not remove all noindex tags or redirect every 404 to the homepage. Account/filter/provisional-language/stale pages may intentionally be excluded; removed pages can correctly return 404. The current fixes do not prove that all 590 reported URLs are repaired or indexed.

Next evidence required: URL exports for each group, especially the 533 and four canonical conflicts; URL Inspection details for user-declared canonical, Google-selected canonical and last crawl date. Group by template and verify meaningful unique content, indexability, internal links, final URL and rendered HTML. National/state price-history overlap is a candidate for review, not a proven explanation for the four conflicts. Do not consolidate all such pairs without inspection.

After live verification, submit https://sahibhav.in/sitemap.xml in Search Console and request indexing for a small representative set of valuable corrected URLs. Repeated requests do not accelerate crawling and inclusion is not guaranteed.
