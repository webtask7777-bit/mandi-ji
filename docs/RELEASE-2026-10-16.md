# SahiBhav crop coverage and delivery update

## Delivered

- Expanded the shared crop photo catalogue; see `CROP-COVERAGE-UPDATE.json` for exact raw-catalogue and served-catalogue coverage and remaining IDs. Every bitmap has a prompt manifest. Unknown or ambiguous commodity forms retain the neutral icon.
- Corrected Hindi display names by exact commodity ID while retaining original English names, IDs, varieties, dates and price values.
- Replaced the transport destination with a delivery calculator at `/delivery-calculator`; `/transport` redirects. Dashboard tab links are bookmarkable.
- Calculator includes vehicle payload, packaging weight, full trips, one-way/return kilometres, rate or complete-trip quotation, minimum fare, toll, loading, packing, market fee, other costs and spoilage. It shows usable quantity, total cost, landed cost per kg, local-purchase/resale difference and break-even distance when meaningful.
- Each vehicle needs its own entered freight and toll. No live freight tariff or manufacturer payload claim is invented. Kg/quintal/tonne changes retain the physical quantity. Drafts and up to five scenarios are stored locally; copy/download is user initiated.
- Price cards, compatible mandi pairs and active sell listings open the calculator with source context. Listing offers remain distinct from reported mandi observations. Changing routes clears old freight assumptions.
- Polished price, calendar, mandi, map, marketplace and listing-detail layouts, mobile fields, crop images, saved-crop controls, loading/error states and expired-listing handling.
- Public marketplace browsing keeps existing contact permissions. Masked phone numbers never become callable links. Authentication preserves listing type and crop intent using validated internal destinations.
- Map filtering compares exact normalized crop names. Missing entries in incomplete top-crop lists mean unknown, not crop absence.
- Eleven explicit livestock/animal-product entries are withheld from crop price/ticker/comparison APIs because their units cannot safely be treated as crop quintals. Original source JSON is preserved; direct requests receive a clear unit error. Cowpea is not excluded.
- Service worker cache version advances to v5, retaining JavaScript/CSS MIME validation and API cache exclusion.

Production build and targeted regression suites cover cost arithmetic, capacity boundaries, packaging, quote/rate separation, unknown costs, unit conversion, provenance, price cohort matching, date freshness, display-name boundaries, safe return paths, map evidence and non-crop endpoint guards. Final publication is verified on the production domain.

## Research decisions

- eNAM Agmarknet exposes commodity/variety, min/modal/max, market, unit and date. Preserve these distinctions instead of treating unlike quotes as a trade: https://enam.gov.in/dashboard/agmarknet
- Porter describes provider-specific included charges and extras. Freight is therefore user-entered with explicit toll/return/loading handling: https://porter.in/spot-faq
- TruckSuvidha already offers distance/load discovery; the useful addition here is a crop purchase plus delivery cost comparison: https://trucksuvidha.com/Features.aspx
- Market reporting already exists at Agriwatch; photo polish alone does not establish an acquisition advantage: https://www.agriwatch.com/

## Remaining work

The newest bundled market observation remains 4 April 2026. This release does not refresh market prices or add a live data feed. Staleness stays visible. Before scheduling ingestion, repair date-scoped progress, retries and atomic daily merges; existing manual fetch scripts can otherwise skip dates or overwrite partial records.

Remaining neutral crop categories and ambiguous source forms are enumerated in the coverage report. Add photos only after checking the exact commodity form. Livestock requires a separate verified unit model before reintroduction. Route distance and actual vehicle quotations remain manual inputs. Search traffic needs useful regularly updated crop/mandi pages, reliable ingestion and measurement; neither photographs nor this release guarantee traffic.
